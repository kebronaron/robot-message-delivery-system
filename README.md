# Robot Message Delivery System 🤖📨

A cloud-connected robot message delivery platform designed to connect a web application, backend services, cloud infrastructure, and an embedded ROS 2 system.

This project was developed as a team software engineering project and combines full-stack development, cloud services, database integration, and robotics.

---

## Overview

The Robot Message Delivery System allows users to create and manage delivery messages through a web interface while connecting the application to a robotic delivery system.

The project combines:

- Web frontend development
- REST API communication
- Backend services
- Cloud infrastructure
- Database management
- Embedded/robotics integration
